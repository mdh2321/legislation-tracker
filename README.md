# Legislation Tracker - Singapore, Australia, Japan

A spreadsheet tracking legislation and regulations applicable to global technology companies (e.g., DocuSign, Inc.) operating in Singapore, Australia, and Japan.

## Spreadsheet Structure

The `legislation_tracker.csv` file contains the following columns:

| Column | Description |
|--------|-------------|
| Country | Jurisdiction (Singapore, Australia, Japan) |
| Legislation/Regulation | Official name of the law or regulation |
| Category | Type: Data Privacy, Electronic Signatures, Cybersecurity, AI/Technology, Criminal |
| Status | Active, Upcoming, Pending Implementation, Proposed |
| Effective Date | When the legislation came/comes into force |
| Compliance Deadline | Key dates for compliance requirements |
| Key Requirements | Summary of main obligations |
| Relevance to Tech Companies | Impact assessment (Critical, High, Medium, Low) with explanation |
| Penalties | Potential fines and sanctions for non-compliance |
| Regulatory Body | Authority responsible for enforcement |
| Notes/Updates | Recent amendments, upcoming changes, or important context |
| Source | Reference URL for more information |

## Key Legislation by Category

### Electronic Signatures (Critical for DocuSign-type businesses)
- **Singapore**: Electronic Transactions Act (ETA) 2010 (amended 2021)
- **Australia**: Electronic Transactions Act 1999
- **Japan**: Electronic Signatures and Certification Business Act

### Data Privacy
- **Singapore**: Personal Data Protection Act (PDPA)
- **Australia**: Privacy Act 1988 (Tranche 1 reforms effective December 2024)
- **Japan**: Act on Protection of Personal Information (APPI)

### Cybersecurity
- **Singapore**: Cybersecurity Act 2018 (amended 2024)
- **Australia**: Cybersecurity Compliance Framework (Phase 2 from January 2026)
- **Japan**: Basic Act on Cybersecurity, Active Cyber Defense Act

### AI/Technology
- **Singapore**: AI Governance Framework (voluntary)
- **Australia**: AI Guardrails (expected 2026)
- **Japan**: AI Promotion Act (effective September 2025)
